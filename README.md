# Human Oversight Behaviors Dataset
This repository contains a developer-LLM interaction dataset curated from [WildChat-4.8M](https://huggingface.co/datasets/allenai/WildChat-4.8M) and annotated by human expert for presence of Human Oversight Behaviors as described in (cite our paper).
